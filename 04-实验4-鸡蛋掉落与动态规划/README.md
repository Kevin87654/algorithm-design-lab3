# 实验 4：鸡蛋掉落与动态规划

## 实验目标

使用动态规划解决鸡蛋掉落问题，在给定鸡蛋数和楼层数时，求最坏情况下确定临界楼层所需的最少试验次数。

## 实现内容

报告中记录了状态定义、边界条件、状态转移方程、核心伪代码、复杂度分析以及与蛮力递归方法的比较。

## 核心知识点

动态规划、最优子结构、重叠子问题、最坏情况最优化、二维状态表和复杂度分析。
