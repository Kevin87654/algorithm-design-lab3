# 实验 2：最近点对与分治法

## 实验目标

求解二维平面点集中的最近点对，分别实现蛮力法和分治法，并通过不同规模的随机点集比较理论效率与实测效率。

## 实现内容

- 随机生成二维点集。
- 使用两层枚举实现蛮力法。
- 按横坐标划分点集，递归求解左右子问题并检查中间条带。
- 绘制性能曲线和算法过程可视化。

## 核心知识点

分治法、递归、最近点对、欧氏距离、蛮力基准、时间复杂度和 Matplotlib 可视化。

## 主要文件

- [`src/closest_pair0.py`](./src/closest_pair0.py)：包含蛮力法、分治法、性能测试和结果可视化的主要版本。
- [`src/closest_pair.py`](./src/closest_pair.py)：侧重展示分治求解过程的动态可视化版本。
- [`src/draw_chart.py`](./src/draw_chart.py)：用于批量测试并绘制理论与实测性能曲线。
- [`report/实验二报告.docx`](./report/实验二报告.docx)：课程小组实验报告。

## 版本关系

三个 Python 文件共享最近点对的核心问题，但分别侧重综合测试、动态演示和性能图表，因此作为有实际意义的不同实现保留。

本目录保留课程完成时的原始代码和报告状态，未对算法或实验结果进行重新设计和验证。
