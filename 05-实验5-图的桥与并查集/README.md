# 实验 5：图的桥与并查集

## 实验目标

找出无向图中的全部桥边，实现按桥定义逐边检查的基准算法，并设计使用并查集的更高效算法。

## 实现内容

- 使用邻接表保存无向图，并为每条边分配唯一编号。
- 基准算法逐条忽略边，通过 DFS 重新计算连通分支数量。
- 高效算法生成 DFS 森林，使用非树边识别环上的树边。
- 使用并查集压缩已经处理过的树路径，减少重复回溯。

## 核心知识点

桥、连通分支、DFS、生成森林、树边与非树边、并查集和路径压缩。
