# 实验 1：AI 推荐系统中的 Top-k 优化

## 实验目标

模拟推荐系统中用户相似度计算与 Top-k 用户选择过程，分析不同排序和选择方法的时间复杂度，并比较其在不同输入规模和不同 k 值下的效率。

## 实现内容

- 使用余弦相似度衡量用户兴趣向量的相似程度。
- 比较快速排序、归并排序、部分选择排序和最小堆方法。
- 使用稀疏字典表示非零兴趣特征，观察稀疏度对相似度计算的影响。
- 保存实验使用的性能数据和汇报材料。

## 核心知识点

余弦相似度、Top-k 查询、排序算法、最小堆、稀疏向量、时间复杂度、理论效率与实测效率比较。

## 主要文件

- [`src/code.py`](./src/code.py)：Python 综合实现，包含稠密数据实验、四种 Top-k 方法及稀疏数据测试。
- [`src/稀疏矩阵.py`](./src/稀疏矩阵.py)：单独的稀疏向量实验实现。
- [`src/ConsoleApplication1.cpp`](./src/ConsoleApplication1.cpp)：C++ 版本的主要性能比较程序。
- [`results/图表.xlsx`](./results/图表.xlsx)：不同算法、数据规模和 k 值下的实验数据。
- [`report/实验报告.docx`](./report/实验报告.docx)：课程实验报告。
- [`notes/演讲稿.docx`](./notes/演讲稿.docx)：实验汇报时使用的演讲稿。
