# 实验 3：地图着色与回溯法

## 实验目标

将地图着色问题建模为无向图着色问题，使用回溯法寻找满足相邻顶点颜色不同约束的着色方案，并观察图规模对搜索效率的影响。

## 实现内容

- 读取 DIMACS `.col` 图数据。
- 实现按顶点顺序尝试颜色的基础回溯算法。
- 实现结合 MRV、静态度数、前向检查和超时保护的优化回溯算法。
- 使用随机图测试图规模与执行时间的关系并生成结果图。

## 核心知识点

图建模、回溯、约束满足、剪枝、MRV、前向检查和搜索规模分析。

## 主要文件

- [`src/main.py`](./src/main.py)：图结构、数据读取、基础回溯和优化求解器的主要入口。
- [`src/graph_generator.py`](./src/graph_generator.py)：随机图规模测试与结果图生成程序。
- [`data/`](./data/)：三个课程实验使用的 `.col` 图数据集。
- [`results/scale_vs_time.png`](./results/scale_vs_time.png)：图规模与执行时间关系图。
- [`report/实验报告.docx`](./report/实验报告.docx) 与 [`report/实验报告.pdf`](./report/实验报告.pdf)：最终实验报告的 Word 和 PDF 版本。
