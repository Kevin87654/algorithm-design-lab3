
## ✨ 核心实现
本实验采用**回溯法**解决地图着色问题，核心逻辑如下：
1.  **问题建模**：将地图转化为无向图，每个地区对应一个顶点，相邻地区之间用边连接。
2.  **回溯搜索**：从第1个顶点开始，为每个顶点尝试分配颜色，若当前颜色与相邻顶点不冲突则保留，否则回溯到上一个顶点尝试下一种颜色。
3.  **剪枝优化**：在分配颜色时提前检查相邻顶点，避免无效搜索路径。
