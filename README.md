# 算法设计与分析实验5：图论（桥）

本仓库保存算法设计与分析实验5的源代码。

## 实验内容

实验目标是找出无向图中的所有桥边。

程序实现了两种算法：

1. 基准算法：逐条忽略边，并使用 DFS 重新计算连通分支数量。
2. 高效算法：使用 DFS 生成树，并结合并查集处理非树边形成的环。

## 文件说明

- `bridge.cpp`：实验源代码。

## 数据文件

程序运行时需要将老师提供的数据文件放在可执行程序同一目录下：

- `mediumG.txt`
- `largeG.txt`

由于数据集文件较大，且属于课程提供的数据文件，本仓库只提交源代码。

## 运行方式

在 Windows PowerShell 中可以使用如下方式编译：

```powershell
clang++ -std=c++17 -O2 bridge.cpp -o bridge.exe
```

运行程序：

```powershell
.\bridge.exe
```

程序会依次完成：

1. 图2示例的正确性验证。
2. `mediumG.txt` 数据集测试。
3. `largeG.txt` 数据集高效算法测试。

## 实验结果示例

图2示例中，基准算法和高效算法均找到 6 条桥，验证结果为 PASS。

`mediumG.txt` 中，两个算法均找到 0 条桥，结果一致。

`largeG.txt` 中，高效算法找到 8 条桥。
