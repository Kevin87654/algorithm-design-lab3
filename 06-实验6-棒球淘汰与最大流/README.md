# 实验 6：棒球淘汰与最大流

## 实验目标

将棒球淘汰问题转换为最大流问题，判断一支球队是否仍存在获得最高胜场数的可能，并理解最大流最小割定理在实际建模中的应用。

## 实现内容

- 为待判断球队计算理论最大胜场数。
- 构建源点、比赛节点、球队节点和汇点组成的流网络。
- 使用 Edmonds–Karp 算法在残量网络中反复寻找增广路。
- 根据最大流是否覆盖全部剩余比赛判断球队是否被淘汰。

## 核心知识点

网络流建模、容量、残量网络、BFS 增广路、Edmonds–Karp、最大流最小割和棒球淘汰问题。
